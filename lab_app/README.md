# GL261 Segmentation Assistant — приложение для лаборатории

Локальное веб-приложение: загружаете МРТ-срез мыши — получаете разметку
опухоли, отёка и некроза и их площадь. Работает офлайн, без видеокарты,
всё считается на вашем компьютере — ничего не отправляется в интернет.

## Установка и запуск (Windows)

1. Если на компьютере ещё нет Python — поставьте Python 3.10+ с
   [python.org/downloads](https://www.python.org/downloads/) и на экране установки
   поставьте галочку **"Add python.exe to PATH"**.
2. Скопируйте папку `lab_app` целиком на компьютер.
3. Дважды кликните **`run_app.bat`**.
   - При первом запуске нужен интернет на пару минут — скачаются нужные
     библиотеки. Дальше приложение работает полностью офлайн.
   - Откроется окно браузера с приложением. Не закрывайте чёрное окно
     консоли, пока пользуетесь программой — им приложение и работает.
4. Чтобы закрыть приложение — закройте окно консоли.

Если Windows заблокирует запуск `.bat`-файла ("Windows защитила ваш
компьютер") — нажмите "Подробнее" → "Выполнить в любом случае" (файл не
содержит ничего, кроме команд установки Python-пакетов и запуска
приложения — можно свериться, открыв его в блокноте).

## Как пользоваться

1. Слева — статус модели и настройки.
2. В основном окне — кнопка загрузки снимка: PNG, JPG или DICOM (.dcm).
3. Нажмите **«Запустить анализ»**.
4. Результат:
   - исходный снимок и снимок с наложенной разметкой (оранжевый =
     опухоль, синий = отёк, розовый = некроз);
   - площадь каждого региона в пикселях и, если известен физический
     масштаб снимка, в мм²;
   - таблицу и кнопку **«Скачать отчёт (.txt)»**.
5. Если снимок не DICOM (нет физического масштаба в файле) — укажите
   размер пикселя в мм в боковой панели, чтобы увидеть площадь в мм², а
   не только в пикселях.

## Что на самом деле внутри

- Модель — компактная U-Net (2D, ~4.4 млн параметров), обученная **с нуля**
  на 252 размеченных срезах из 15 мышей датасета `Mice_gbm`/
  GL261-MRI-Segmentation (разбиение по животным, чтобы срезы одной мыши
  не попадали одновременно в обучение и проверку).
- Это **не** воспроизведение baseline-моделей из статьи (там —
  nnU-Net/EfficientNet-B0 с GPU, 5-кратной кросс-валидацией и 150
  эпохами на 538 срезах). Это отдельная, лёгкая модель, специально
  подобранная под ноутбук без видеокарты — со своим качеством, которое
  указано в приложении (`model/model_meta.json`, поле `best_mean_fg_dice`).
- Регионы и их площадь оцениваются по внешнему виду на МРТ, как и в
  статье — это не гистологическое подтверждение опухоли, отёка или
  некроза.

## Ограничения — прочитайте перед использованием

- **Это исследовательский инструмент, не для клинической диагностики
  или решений о лечении.**
- Модель училась всего на 15 мышах — метрики качества (Dice) в
  приложении показывают, насколько ей вообще можно доверять на новых
  снимках; они основаны на 3 животных, не участвовавших в обучении.
- Если снимок сильно отличается от обучающих (другой протокол
  сканирования, другая контрастность, другой ракурс) — результат может
  быть неточным. Всегда сверяйте с исходным снимком глазами.
- Площадь в мм² верна настолько, насколько верен указанный вами (или
  прочитанный из DICOM) размер пикселя.

## Переобучение модели

Если появятся новые размеченные данные — модель можно переобучить:

```
cd lab_app/scripts
python train.py --data-root <папка с животными: JPEGImages/ + SegmentationClass/ на каждое> --epochs 100
```

Обучение полностью на CPU, на исходном датасете (252 среза, 15 животных)
занимает около 35–40 минут на обычном 4-ядерном ноутбуке. Новый
чекпоинт автоматически сохранится в `model/unet_gl261.pt` и подхватится
приложением при следующем запуске.
