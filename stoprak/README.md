# СТОП-РАК — интерактивный прототип рабочего пространства врача

Прототип по ТЗ `STOP-RAK_SITE_SPEC.md`: главная страница + рабочая станция для МРТ глиобластомы.
Работает целиком в браузере (статический сайт, без сборки и бэкенда).

## Запуск

```bash
cd stoprak
python3 -m http.server 8000          # или: nohup python3 -m http.server 8000 >/tmp/stoprak.log 2>&1 &
# открыть http://localhost:8000
```

Можно также просто открыть `index.html` двойным кликом: сайт собран в `dist/app.js`, а данные продублированы в `data/*.js`, поэтому `file://` работает. Браузер — современный Chrome/Edge/Firefox/Safari с WebGL2.

Пересборка после правок в `js/`: `npx esbuild js/app.js --bundle --format=iife --outfile=dist/app.js --minify`.

## Что внутри

| Возможность | Реализация |
|---|---|
| **Реальные МРТ** | 3 случая из открытого набора **OpenNeuro ds007045** (глиобластома, 4 последовательности T1 · T1-Gd · T2 · FLAIR, MNI152, без черепа, N4) + маски BraTS (некроз / отёк / активная опухоль), проверенные нейрорадиологами авторов набора |
| **2D MPR** | аксиальная / сагиттальная / корональная плоскости на canvas: синхронный курсор, окно/уровень, масштаб, панорама, линейка (мм), ROI, инверсия, кино |
| **3D** | собственный объёмный ray-marching на WebGL2 (`js/vr.js`, three.js): полупрозрачный мозг по T1, поверхности зон опухоли, клиппинг-плоскость с **настоящим срезом МРТ на разрезе**, вращение/масштаб мышью, клик → переход к точке в 2D, подсказки с объёмом |
| **Локальная загрузка** | `.nii` / `.nii.gz` (NIfTI-1) и несжатый **DICOM** (файлы или папка, группировка по сериям) читаются в браузере, на сервер ничего не уходит; проверка качества; без подключённой модели — «просмотр доступен, анализ не подключен» |
| **Сегментация** | демо-запуск с этапами и прогрессом; результат — маски датасета; слои, прозрачность, контур/заливка; ручная коррекция (кисть, ластик, удаление области, undo/redo), версии, журнал, подтверждение врачом |
| **Показатели** | объёмы (см³), доли, диаметр, бидименсиональные размеры, очаги, локализация (по MNI, ориентировочно) — считаются по маске и пересчитываются после правок |
| **Сравнение** | базовое ↔ контрольное, разность масок (рост / уменьшение), таблица, график |
| **Лечение** | исходно — две кнопки без результатов; «Моделирование» (форма → расчёт → штрихованная модельная маска в 2D/3D с диапазоном) и «Подбор терапии» (проверка данных → до 5 сценариев с осями оценки, рисками и ссылками) |
| **ИИ-помощник** | выдвижная панель, контекст, быстрые команды, ответы по данным открытого случая, источники со ссылками, действия только по кнопке |
| **Заключение** | редактор черновика, связь чисел с источником, версии, подпись, экспорт TXT |
| **Прочее** | палитра команд (Ctrl/⌘+K), горячие клавиши (`?`), режим для дальтонизма, скрытие персональных данных, отключение анимации, экспорт маски NIfTI / JSON / PNG |

## Честные ограничения (важно)

* **Динамика.** В датасете только дооперационные исследования. «Контроль +3 мес» и модельные сценарии лечения — **синтетика**: игрушечная модель (`js/model.js`, `simulateMask`) эрозирует реальную маску. Везде помечено «синтетическая демо-динамика» / «модельный сценарий»; это не прогноз и не клинически валидированная модель.
* **Сегментация** в демо — предрассчитанные маски датасета (SegResNet + правки нейрорадиологов), а не запуск модели в браузере. Точки подключения реальной модели: `runSegmentation()` в `js/app.js`.
* **Подбор терапии** — качественные сценарии по опубликованным схемам (Stupp 2005, Perry 2017, Stupp 2017, Herrlinger 2019, EANO 2021) с DOI; оценки не объединяются в единый рейтинг. Не является назначением лечения.
* Не реализовано: интерполяция маски между срезами, пороговое выделение, сжатый DICOM (JPEG и др.), ZIP/PACS, разрезы «шторка/наложение» в сравнении, консилиум как отдельный экран (есть повестка).
* Это не медицинское изделие.

## Структура

```
index.html          главная + рабочая станция + модальные окна
css/app.css         дизайн-система
js/nifti.js         чтение NIfTI-1 (gzip), приведение к RAS+
js/vr.js            3D-рендер (WebGL2 ray-marching)
js/mpr.js           2D-просмотрщик срезов и инструменты
js/model.js         метрики по маске, демо-модель, сценарии терапии, тексты
js/app.js           состояние рабочей станции, сегментация, раскладки, экспорт
js/panels.js        правая панель: слои / показатели / сегментация / лечение
js/ai.js, report.js, upload.js   помощник, заключение, локальная загрузка (NIfTI + DICOM)
data/<sub>/         подготовленные uint8-NIfTI (RAS+, обрезаны по мозгу) + case.json
tools/prepare_data.py  подготовка новых случаев из ds007045
vendor/             three.js r160 (MIT)
```

### Добавить другой случай

```bash
pip install nibabel numpy scipy
python3 tools/prepare_data.py --raw <папка с sub-XXX_{t1,t1ce,t2,flair,mask}.nii.gz> \
    --participants participants.tsv --out data sub-XXX
```
и добавить id в `DEMO_CASES` в `js/app.js`. Файлы берутся из `derivatives/processing` и `derivatives/segmentation` датасета.

## Данные и лицензии

Изображения и маски — Filimonova E. et al., *Glioblastoma MRI Dataset with Standardized Preprocessing, Expert-Validated Segmentation, and MGMT Profiling*, Sci Data 2026;13:1213 · OpenNeuro [ds007045](https://doi.org/10.18112/openneuro.ds007045.v2.0.1) · лицензия **CC0**. Данные обезличены авторами набора. Метки: 1 — некроз/неусиливающееся ядро, 2 — отёк (FLAIR), 3 — активная опухоль.
